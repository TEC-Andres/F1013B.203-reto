\inicializarSeccion{Funcionamiento de App Designer y como acceder a el}
\tab App Designer es una herramienta de MATLAB que permite a los usuarios crear aplicaciones gráficas de manera sencilla e intuitiva. 
\inicializarSubseccion{Como acceder a App Designer}
Para acceder a App Designer, puedes seguir estos pasos:
1. Abre MATLAB en tu computadora.
2. En la barra de herramientas superior, haz clic en la pestaña "Apps".
3. Selecciona "Design App" y entra al portal de App Designer.

\inicializarSubseccion{Ventanas de App Designer}
\tab App designer tiene dos ventanas, la del diseño, en donde puedes agregar los componentes de tu aplicación (sliders, botones, gráficos, etc.) y la ventana de código, en donde puedes programar el comportamiento de cada componente que agregaste en la ventana de diseño. La ventaja de esto, es que puedes programar cada componente de manera independiente; tratandolo como un objeto, haciendo que el código sea mas organizado y fácil de entender. Aparte, desde antes puedes ver como se va a ver tu aplicación, lo que hace que el proceso de diseño sea mas sencillo.

\tab Demonstrando un poco el poder de esta tecnología, tomaremos el ejemplo de un botón. Este componente funciona como un objeto, la cuál nos permite acceder a sus propiedades de manera directa en el editor de componentes. Por ejemplo, si quisieramos renombrar el botón, solo tendríamos que acceder desde el editor de componentes y cambiar la propiedad de "Text". En la cuestión de código, podemos agregarle a este botón un callback, lo cuál nos permite hacer una acción con este botón en donde podemos realizar acciones. A continuación, se muestra un ejemplo de un callback en donde actualiza el plot de la aplicación cada vez que se presiona el botón.

\begin{lstlisting}[style=Matlab-editor]
% Button pushed function: CorrerSimulacinButton
function CorrerSimulacinButtonPushed(app, event)
    app.updatePlot();
end
\end{lstlisting}

\tab Entrando tambien en detalles de funciones, cada función esta dentro de una clase; siendo la clase predeterminada la clase de la aplicación. Esto hace que para acceder a ciertas propiedades de la aplicación, tenemos que usar los principios de la programación orientada a objetos. Como se vio en el ejemplo del botón, para acceder a la función de actualizar el plot, tenemos que usar la sintaxis de \texttt{\textbar app.updatePlot()\textbar}. Esto hace que el código sea mas organizado y fácil de entender, ya que cada función esta claramente definida dentro de su clase correspondiente.

\tab Ya con esto, si queremos concretar el funcionamiento, lo único que tendriamos que hacer es colocar la figura en nuestra aplicación. Esto se hace escogiendo el componente \texttt{\textbar axes\textbar} y acomodando el componente. De esta manera, podremos tener nuestro plot dentro de la aplicación, y de esta forma, poder mostrar lo que nosotros queramos mostrar en el plot.
